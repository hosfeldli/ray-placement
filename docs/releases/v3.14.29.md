# Lima v3.14.29 — native capability and Workbench foundations

This is a **limited release** of the implemented changes, not completion of the Browser and AI Workbench redesign. The requester explicitly authorized publication with the remaining gaps disclosed in `docs/EMBEDDED_BROWSER_RELEASE_GATE.md`. Unchecked acceptance items remain open.

## Included

- Add a shared native-capability authorization foundation with host-side routing and one-use, run-bound exact-call review for eligible AI and extension actions. Capability declarations do not themselves grant access.
- Add Screenshot Studio capture/history and destination controls, optional OCR support, audio-output selection and favorites, and an opt-in network-quality utility. These features have automated fixture coverage, not complete live-device acceptance.
- Improve embedded Browser tab mounting, semantic interaction, secure-field handling, guarded final actions, and post-action verification. Expand local WebKit regressions for tab switching, frames, forms, screenshots, and user takeover.
- Add Workbench and terminal foundations, including asynchronous ordered terminal-output draining and bounded managed-server tooling. Improve completed long-answer scrolling and stabilize the Swift test runner by running every discovered case in bounded groups with hosted-view fixtures isolated.

## Validation and known limits

- The development source commit `9022c978f7a00729b79600f1dc67e357f176be20` passed hosted CI. The local final development tree passed all 609 discovered Swift tests exactly once, Debug and Release builds, the deterministic Workbench self-test gate, and an offscreen visual audit of 205 renders with no failures. The separate version-commit CI and hosted release checks must also succeed before publication.
- Live multi-display/Retina capture, clipboard and focus restoration, OCR/Search behavior on real captures, and physical audio switching have not completed on-device acceptance. A speed-test measurement must be explicitly initiated; automated parser tests are not a live throughput test. Calendar and Reminders services and actions remain incomplete.
- The requested single authoritative Workbench action timeline, complete Browser-sidecar integration and tab-scoped visual acceptance, and project-owned Process runtime with process-group control, artifact-backed paged logs, server tracking, and Process panel remain incomplete. The asynchronous terminal-output drain alone does not supply that runtime.
- Packaged-app response repaint, Browser safety/accessibility on real sites, live-site reservation, signed-app interaction, and comparative performance profiling remain unverified. Unit tests and offscreen renders do not establish those outcomes. Do not make a real booking or purchase as part of release validation without separate user authorization.
- v3.14.29 is subject to successful CI on its exact version commit, immutable tagging, hosted signing, staged-artifact integrity checks, and verification of the public release and all required assets. No failed security or distribution check is waived by this limited-release authorization.
