# Lima v3.14.27 — AI response presentation and Workbench stabilization

This is a **limited stabilization release**, not completion of the project-centered AI Workbench or the full embedded Browser acceptance plan. The requester directed publication with remaining verification-only checks non-blocking. Open checks remain documented in `docs/EMBEDDED_BROWSER_RELEASE_GATE.md`.

## Included

- AI chat now publishes answer text and reasoning summaries through an observable streaming snapshot. Live and completed assistant rows are separate; the live reasoning disclosure observes the snapshot directly, and answer/reasoning batches flush independently.
- Finalization commits the assistant message to the conversation store before switching to the completed row and clearing the live projection. A storage-limit rejection cannot be mistaken for a successful commit. Completed runs cannot legally retain the active `Working…` presentation.
- Codex chat now uses a persistent streamed app-server bridge with native Lima tools, concurrent call IDs, same-turn continuation, and streamed or completed reasoning summaries. Raw private reasoning text is not displayed. Legacy buffered CLI behavior remains for older paths, not production Codex chat.
- Workbench tool routing now uses a shared capability snapshot and revalidates permissions at execution time. Browser human takeover and lazy tab loading have clearer authority and failure behavior. AI Workbench diagnostics and self-tests report provider, tool, Browser, and Terminal state.
- Performance diagnostics distinguish first provider output from first visible answer text.
- Release build, staging, and publication require deterministic Browser, PTY, file, registry, app-server, and AI presentation regressions. The signed-in live Codex check remains available via `scripts/release_workbench_gate.sh --live`; hosted builds do not require a developer's personal Codex session.

## Validation and limits

- Before version preparation, the local source tree passed 503 Swift tests, a Release build, the deterministic Workbench checks plus a separate signed-in live Codex native-tool check, signed-app packaging/verification, installer and update-verifier regressions, and an offscreen audit of 205 PNG fixtures with zero failed renders.
- These automated checks do **not** establish packaged-app live answer/reasoning repaint, cancellation or approval-continuation visuals, reasoning-heavy live Codex presentation, real-site Browser safety/accessibility, or production frame pacing and memory.
- Persistent attached workspaces, complete Browser state preservation, broad Workbench tool families, off-main run ownership, and end-to-end task acceptance remain incomplete. Do not describe this release as the full Browser or AI Workbench.
- Publication still requires exact-commit CI, immutable tagging, hosted signed artifact validation, draft verification, and public asset/digest verification. None of those checks should be claimed complete until their corresponding workflow results exist.
