# Lima 4.0.0 — A More Capable Lima

*A major evolution of Lima's AI, Browser, and native macOS integrations.*

Lima 4.0 brings a more capable, connected macOS assistant. Search, AI, the embedded Browser, Notes, system controls, and native Apple applications work together more closely while preserving Lima's familiar prismatic interface.

This is a **limited-scope major release** of the implemented capabilities below, not completion of every Browser, Workbench, Mail, or Messages acceptance item. Preview capabilities and known limitations are disclosed explicitly.

## New Features

### A More Capable AI Workbench

- **Advanced Notes editing:** AI can update existing Notes, edit specific Markdown blocks, manage checklist tasks, move content between Notes, and work with attachments.
- **Improved context awareness:** Better integration with Browser pages, Notes, selected text, files, Mail, Messages, and Context Shelf.
- **Intelligent error handling:** More detailed explanations for API and CLI failures, with automatic recovery for supported transient errors.
- **Task preservation:** Execution checkpoints help preserve unfinished AI work when providers are interrupted.
- **Clearer activity tracking:** Improved presentation of tool execution, reasoning summaries, and task outcomes.

### A More Powerful Embedded Browser

- Combined semantic and screenshot-based page understanding.
- Native pointer movement, visual clicking, and typing where the configured Browser mode and macOS permissions allow them.
- Improved handling of dynamic websites and changing page layouts.
- Stronger safeguards against stale screenshots and unintended actions.
- More precise handling of tabs, navigation, and interaction state.
- Additional review for potentially consequential website actions.

These additions provide more ways to interact with websites while preserving user control. A dispatched Browser action is not proof of the requested website outcome.

### Native Audio Output Control

Switch between connected audio devices from Search, General Settings, and the Activity Shelf. Lima can select compatible built-in, Bluetooth, USB, display, and other macOS output devices when available. Supported devices expose volume and mute controls; Lima observes macOS changes and checks the selected system output after a switch.

### Apple Mail Integration — Preview

Lima introduces account-scoped Mail search and reading, AI-assisted drafts, replies, forwards, and reviewed outgoing messages. Correspondence can support editable Notes, action extraction, and Reminders. Mail access and sending require explicit authorization; sending is off by default. **Live sending and reply behavior have not completed release acceptance.** An Apple Mail send request is not proof of delivery.

### Messages Integration — Preview

Lima can search and read selected local conversations, summarize message history, prepare text replies, open a composer for user-reviewed sending, extract tasks, create source-linked Notes and Reminders, and propose Calendar events from selected-message evidence. Reading requires Full Disk Access and explicitly selected conversations. The current native send adapter supports text only; attachment sending is a manual handoff, and continuous incoming-message monitoring is not available.

### Calendar, Reminders, Contacts, and Location

With the relevant macOS permissions, Lima AI can find and manage Calendar events, work with Reminders, search Contacts and perform approved updates, and request the Mac's current location when a task needs it. Writes continue to use Lima's action-review boundaries.

### Screenshot and Text Capture

New capture capabilities include region screenshots, region-based text recognition and copying, screenshot history, and handoffs into supported Lima actions. Some region-capture capabilities require macOS 14 or later.

### Dictation and Updates

Dictation gains optional cloud transcript postprocessing and improved compact controls. Lima can now show update highlights, detailed in-app release notes, locally retained version history, and an optional skippable major-update introduction. The signed update mechanism remains responsible for installation; release notes cannot authorize an update.

## Improvements

- Improved Search result selection, action routing, inline measurement conversions, audio-output commands, and preservation of user selection.
- Better handoffs among application resources, task activity, Mail and Messages references, and larger changing tool outputs.
- More precise Notes edits, source-linked action items, Markdown tables, rich content, and safeguards against overwriting concurrent changes.
- Extension-loading refinements, more consistent action registration, and broader native tool access across supported AI providers.

## Fixes and Reliability

- Improved Browser protection against stale screenshots and viewport changes.
- Better handling of repeated AI actions that fail without progress.
- More informative API and CLI provider errors and improved handling of interrupted responses and uncertain tool outcomes.
- Additional Search, AI continuation, and Markdown interaction refinements.

## Removed Features

### Workflows Has Been Retired

The dedicated Workflows editor, catalog, execution interface, Search scope, and navigation entry have been removed. **AI multi-tool execution, native tools, and Extensions remain available.** Previously saved workflow definitions are preserved in inactive private archives with explicit export and cleanup options.

## Security and Compatibility

- Lima targets macOS 13 or later; certain capture capabilities require macOS 14.
- Mail and Messages remain opt-in and require the appropriate macOS permissions. AI access to communication content uses selected account or conversation scopes.
- Consequential Browser actions retain review requirements.
- Audio output changes are checked against the system's actual selected output.
- Update metadata cannot bypass signed installation requirements.

## Known Limitations

Apple Mail sending and replies have an unresolved live-send acceptance case. A self-addressed signed-QA retest shown in Inbox is evidence of receipt, **not** evidence that the matching Sent and Outgoing states reconciled or that every send/reply path is accepted. Do not repeat an uncertain send solely to investigate it.

Messages supports native text-based sending but not native attachment sending or continuous incoming-message monitoring. Complex real-site Browser behavior, live-device and accessibility behavior, and installed-update flows still require broader acceptance. The separately proposed autonomous Game Mode and RTS Commander are **not included**.

The candidate source passed 756 discovered Swift tests, a warning-free Release build, the deterministic Workbench gate, and an offscreen light/dark visual audit with no failed renders. Exact-version CI, hosted signing, artifact integrity, and public-asset checks remain mandatory for publication; automated fixtures do not establish the open live acceptance items.
