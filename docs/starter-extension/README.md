# Lima starter extension

1. Copy this directory into `~/Library/Application Support/Lima/Extensions/`.
2. Replace the extension and command IDs with stable identifiers.
3. Edit the fields and execution using `../EXTENSION_AUTHORING_FOR_AI.md`.
4. Validate against `../extension-manifest.schema.json`.
5. Reload Extensions in Lima and test success, failure, timeout, and cancellation.
