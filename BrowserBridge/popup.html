Site access

Reading stays allowed until revoked. Only explicitly granted sites share tab URLs/titles, visible text, links, and selection with Lima. AI context may go to the provider selected in Lima. Private windows and form fields are excluded.

    Interaction access is separate and defaults to Ask every time. It covers bounded tab changes and, with a compatible companion, Lima-confirmed clicks, text entry, and form submission. It never enables arbitrary scripts or password-field access. Revoking reading also clears interaction access; it does not erase context already shared.

    Always allow interactions?

    Lima will be able to dispatch bounded actions for this exact site without another companion prompt, including after restarting the browser. AI click, text entry, and form submission still require an individual confirmation in Lima. Navigation or closing may discard unsaved work. Cross-site navigation requires interaction access on both sites.
