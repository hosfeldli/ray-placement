Site access

Reading stays allowed until revoked. Only explicitly granted sites share tab URLs/titles, visible text, links, and selection with Lima. AI context may go to the provider selected in Lima. Private windows and form fields are excluded.

    Interaction access is separate and defaults to Ask every time. It covers opening, focusing, navigating, and closing tabs—not arbitrary scripts, form filling, or clicks. Revoking reading also clears interaction access; it does not erase context already shared.

    Always allow interactions?

    Lima will be able to open, focus, navigate, and close tabs for this exact site without asking each time, including after restarting the browser. Navigation or closing may discard unsaved work. Cross-site navigation requires interaction access on both sites.
